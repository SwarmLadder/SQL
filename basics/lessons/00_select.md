# 00 · SELECT and columns

**Learn**
- `SELECT` chooses columns; `FROM` identifies the table.
- Use clear aliases with `AS`. Avoid `SELECT *` in stable application queries.

**Run:** `python tools/run_sql.py basics/lessons/00_select.sql`

**Practice**
1. List all SKU codes and product names.
2. Show each customer's name as `customer` and city as `location`.
3. List distinct order statuses.

**Check:** Selecting a column never changes its stored value.
