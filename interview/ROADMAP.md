# Four-Week Backend Interview Plan

| Week | Focus | Deliverable |
|---|---|---|
| 1 | SELECT, JOIN, NULL, GROUP BY | B01–B16; Junior mock |
| 2 | CTEs, windows, reports, N+1 | I01–I16; Backend mock |
| 3 | Keys, transactions, indexes, SQL injection, pagination | A01–A16; run backend lab |
| 4 | Locking, retries, outbox, tenancy, migrations, Postgres | Senior mock + two design cases |

Daily: **20 min concepts · 40 min coding · 15 min explaining design aloud**.

Check your SQL with `python tools/interview_practice.py check ID path/to/answer.sql`. Revisit failed questions after two days. Learn why a query is correct; don't memorize sample output.
