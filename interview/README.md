# Backend SQL interview practice

48 query challenges across Basics, Intermediate, Advanced. Each has a starter file, hint, and reference answer.

```bash
python tools/interview_practice.py list
python tools/interview_practice.py show B10
python tools/interview_practice.py check B10 interview/starter/B10.sql
python tools/interview_practice.py verify-reference
```

Edit a starter file with **one read-only SQL query**, then run `check`. Your result must match the reference on **two datasets**. Column order and listed sort order matter.

Practice before opening `interview/reference/`. Use [mock interviews](MOCK_INTERVIEWS.md), [backend questions](BACKEND_QA.md), and [engineering labs](../backend/README.md).

The checker is for trusted local SQL practice, **not** a sandbox for untrusted code. No production database connections are used.
